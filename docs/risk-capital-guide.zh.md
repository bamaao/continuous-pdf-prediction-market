# 风险资本手册（拍卖与赔付）

给**往预测市场锁定 USDC、提供赔付覆盖**的人看。正式规则以英文产品规格为准：`docs/product-specification.md` §1.2.1、§1.2.6、§6、§8.6。英文通俗版：`docs/risk-capital-guide.md`。冲突时以产品规格为准。

---

## 0. 账本对照（先分清再谈公式）

金库里只有一个 USDC 账户。结算是**分账**，不是四个银行户。

| 账本 | 付给谁 | 不付给谁 |
| --- | --- | --- |
| 交易收入 \(T\) | 赢家（第一优先） | 手续费 |
| 风险资本 \(C_R\) | 赢家（第二，短款抽 \(H\)） | 弥补池保险 |
| 调节池 \(C_P\) | 赢家（第三，有帽） | 风险钱包的累计亏损、手续费 |
| 弥补池 \(S_C\) | 跨市场累计 \(\Pi<0\) 的报价钱包 | 赢家 |
| 手续费 \(\phi\) / 平台盈余 \(S_P\) | 平台（两笔：`claim_fees` 与 `pay_surplus_platform`） | \(C_P\)、弥补池 |

每个预测市场 **Lock ρ 一次**。赢家在 Portfolio 一张票一领；报价在 `/lp` 一笔一领。正式地图：产品规格 §1.2.6。

---

## 1. 你在卖什么

你不是在买预测合约。你是在卖**覆盖**：若到期赢家需要的钱多于本场交易收入，协议最多从你这笔报价抽走 \(D\) USDC。

| 你锁住的 | 最坏 | 最好 |
| --- | --- | --- |
| UserVault 里不少于 \(D\) 的保证金（冻结，不是转走） | 结算抽取最多「已成交的 \(D\)」（记为 \(H\)） | 无需抽取：\(D\) 解锁；若有盈余，按排名领取保费 |

交易侧**不会**因为覆盖不足而拒单。覆盖薄只是警告赢家可能按 \(\rho<1\) 打折。一份保证金**只覆盖一个预测市场**；多个市场要分别锁。

---

## 2. 名词

| 说法 | 意思 |
| --- | --- |
| \(D\)（容量） | 这笔报价最多被抽多少 |
| 保费 premium | 无需抽取时，按排名最多能领到的金额 |
| 单位保费 | \(\mathrm{premium}/D\)，**越低越靠前** |
| \(T\) | 本场交易收入（买家付给预测市场的钱，不含手续费） |
| \(L\) | **实际结果**那一格上的面值合计，不是交易期最热的那一格 |
| \(C_R\) | 已成交并锁定的 \(D\) 之和 |
| \(H\) | 从风险资本抽取的金额：缺口 \((L-T)^+\)，每笔最多其已成交 \(D\) |
| \(\rho\) | 全体赢家同一个赔付比率。\(1\) = 足额 |
| \(S\) | 盈余，仅当 \(\rho=1\)：\(S=\max(T-L,0)\) |
| \(\Pi\) | 这个钱包**跨市场累计**的风险盈亏 |

手续费不进 \(T\)、不进 \(S\)、不进弥补池。

## 3. 时间顺序

```text
审核通过、预测市场开出  →  风险拍卖同时开（哪怕还没人买）
交易与报价并行          →  你报 D / 保费并锁保证金
risk_lock_ts            →  不再接受新报价（不晚于 close_ts）
close_ts                →  不再交易、不再报价；已锁 C_R 冻结
report_open_ts          →  委员会在 24h 报告窗内 submit_result（不得早于 close_ts）
                         窗满未报：等平台 admin_submit_result（扣押金）或 admin_void_resolution（不扣押金）
委员会或平台写入结果并 finalize
begin_settle 锁定 L、T、C_R、ρ、S
到 /lp 领取：先抽 H（若有）→ 保费 → 盈余 → 解锁未用 D
有盈余的场次：Fund cover（把 20% 打入协议弥补池）
若未弥补亏损 > 0：平台可 Claim cover（链上记 Π 与 cover paid）
```

`close_ts` 之后没有「再补一点覆盖」的窗口。

页面：目录 `/auctions`，报价 `/auction/[id]`，领取 `/lp`。必须用**主钱包**，Session 不能报价、不能领钱。

## 4. 怎么报价

在 `/auction/[id]`：

1. **容量 \(D\)**：不低于该场最小额（`d_unit`，默认 10 USDC），更小的作废。
2. **保费**：绝对金额，不是百分比。排名看 \(\mathrm{premium}/D\)。
3. **利润分成**：记在报价上。无需抽取时的盈余按**排名 + 保费上限**发，不按这个字段。一旦发生抽取，本场 \(S=0\)，这个字段也不会发钱。
4. **锁定**：钱包里要有足够可用 USDC；报价是**冻结** \(D\)，不是转给别人。

每个预测市场最多 **64** 笔有效报价。符合条件的报价**整笔**进入同一个池，没有分层塔，没有 10% 集中度上限。后到的便宜或更大的报价照样可以锁进 \(C_R\)。对赢家来说，锁进来的 \(D\) **多多益善**。排名只决定「没人被抽时谁先领盈余」，不限制谁能进场。

---

## 5. 谁排在前面

1. 单位保费最低
2. 相同则时间更早

排名**不是**「短款时先抽谁」。短款时：已成交报价一起补缺口，每笔不超过自己的 \(D\)，直到缺口补上或 \(C_R\) 用尽。

## 6. 三种结算

先按同一个 \(\rho\) 给赢家打款。风险资本是后盾，有剩才谈奖励。

### 情形 A — 交易收入已够（\(L \le T\)）

- 不抽取，\(H=0\)，之后解锁 \(D\)。
- \(\rho=1\)，有盈余 \(S=T-L\)。
- 按第 7 节切开 \(S\)。分给本场报价的 \(S_R\) **按排名发完为止**：
  - 下一家最多拿到**自己报的保费**
  - 再轮到下一名
  - 排在剩余金额后面的拿 **0**
  - 所有保费发完若 \(S_R\) 还有剩，留在本场盈余账上，**不会**再加码超过保费

不是「第一名通吃」。

手续费 \(\phi\) **永远**归协议平台（`claim_fees`），本场打折或作废也一样。\(S_P\) 是本场赢家足额之后、先切 20% 弥补池剩下给平台的那一份，不是 \(\phi\)。短款抽取或作废则 \(S_P=0\)。

### 情形 B — 交易不够，但锁住的 \(D\)（以及可能的 \(C_P\)）仍让赢家足额（\(T < L \le C_{\max}\)）

- 缺口 \(H_{\mathrm{need}}=(L-T)^+\)。
- 从已成交报价抽取，每笔不超过已成交 \(D\)，直到补上。**\(C_R\) 越大越好。**
- \(\rho=1\)，但 \(S=0\)（没有 \(T-L\) 的剩钱）。
- 赢家足额后，仍可领这笔报价的**保费**。
- 没用完的 \(D\) 解锁。

### 情形 C — 连 \(C_R\)（和 \(C_P\)）也不够（\(L > C_{\max}\)）

- 赢家按同一个 \(\rho=C_{\max}/L<1\) 打折。
- 风险资本仍抽到锁定的 \(D\)，用来抬高 \(\rho\)。
- **本场没有盈余**，没有 20% 弥补切片。

### 结果作废 / 终裁失败

保证金解锁，不抽 \(H\)，没有盈余。买家退回买入成本，不按 \(\rho\) 赔付。

### \(\rho\) 和调节池抽多少

调节池**没有**「本场赔付额的百分之几」这种另开一条的规则。它只进入 \(C_{\max}\)，从而进入 \(\rho\)：

1. \(T\) = 本场交易收入（手续费不进；**不算 \(\rho\) 之前不扣保费**）
2. \(L\le T\)：\(\rho=1\)，不抽 \(C_P\)
3. \(L>T\)：交易和已成交 \(D\) 之后的缺口是 \((L-T-C_R)^+\)。本场最多抽 \(\min(\text{该缺口},\;\text{本场 tap},\;\text{池余额})\)。创建时 tap **默认 0**。池子里只有已经 `fund_pool` 进去的钱。
4. \(C_{\max}=T+C_R+C_P^{\mathrm{alloc}}\)，再 \(\rho=\min(1,C_{\max}/L)\)

例：\(T=600\)，\(L=1000\)，\(C_R=300\)，tap \(200\)，池 \(50\) → 抽 \(C_P=50\)，\(C_{\max}=950\)，\(\rho=0.95\)。同样数字 tap \(=0\) → \(\rho=0.90\)。

## 7. 盈余怎么分（只有情形 A）

仅当 \(\rho=1\) 且 \(S>0\)：

```text
S
 ├─ 20%  →  协议「风险亏损弥补池」S_C   （不按本场排名发给报价）
 └─ 80%  →  余下 S̃
      ├─ 本场有成交的 C_R：
      │     默认 70% → 本场报价 S_R（按排名、每笔以保费为上限）
      │     30%     → 平台 S_P
      └─ 本场没有风险资本：
            S_R=0，S̃ 全部给平台
```

数字：\(S=100\) 且有 \(C_R\) → **20 / 56 / 24**（弥补池 / 本场报价 / 平台）。  
没有 \(C_R\) → **20 / 0 / 80**。

\(S_C\) 进**全协议一个账户**，用来弥补**累计亏损**的风险钱包（包括在别的预测市场亏过的）。本场若发生了抽取，则 \(S=0\)，本场**不会**往弥补池打钱。

在 `/lp`：结算后 **Fund cover** 把本场 \(S_C\) 打入池子（随时可打）。金库分开记累计经营盈亏 \(\Pi\) 和已弥补 `cover_paid`。**Claim cover** 由协议平台签名、按情况弥补未补亏损，**没有** 7 天日历窗口。

## 8. 累计盈亏 \(\Pi\) 与弥补池

`UserVault.risk_pnl` 跨所有预测市场累计：

| 事件 | \(\Pi\) |
| --- | --- |
| 被抽 \(H\) | 减 \(H\) |
| 领到保费 | 加保费 |
| 领到 \(S_R\) | 加该笔 |
| 领到弥补 | `cover_paid` 增加；\(\Pi\) **不改** |

弥补规则：未补金额 \((-\Pi)^+ - \texttt{cover\_paid}\)；打入 \(\min(\text{未补},\;\text{池余额})\)；**不按本场排名排队**；未补为 0 则拿 0。只有 **`Market.platform` 签名** 才能 `cover_lp_loss`；何时补是运营选择，不是 unix 窗口。打入池子（Fund cover）随时可以。合约必须把每个 LP 的盈亏和已弥补记清楚。

---

## 9. 硬上限

- 单场抽取不超过该报价**已成交的 \(D\)**。
- 后来交易把 \(L_{\max}\) 抬高，**不会**改写你已锁的 \(D\)。
- 保费是赢家足额之后的奖励，不是从赢家头上扣。
- 不能按盘中价格把报价卖掉离场；未用 \(D\) 只在结算或作废时解锁。
- Session 不能报价、不能领钱。
- 只认 Circle USDC。

## 10. 数字例子

**无需抽取、按排名发盈余。** \(T=1000\)，\(L=800\) → \(S=200\)。  
\(S_C=40\)，余下 \(160\)，\(S_R=112\)，\(S_P=48\)。

| 名次 | \(D\) | 保费 | 单位保费 | 从 \(S_R\) 领到 |
| --- | --- | --- | --- | --- |
| 1 | 100 | 5 | 0.05 | 5 |
| 2 | 100 | 8 | 0.08 | 8 |
| 3 | 200 | 20 | 0.10 | 20 |

三人共领 33。不是第一名拿走 112。每笔停在自己的保费。\(D\) 全部解锁。

**抽取。** \(T=600\)，\(L=1000\)，缺口 400。三笔已成交 \(100+100+200\)。各抽至多 \(D\)，合起来补上 400。\(S=0\)。赢家足额后领保费；\(\Pi\) 先减 \(H\) 再加保费。

**跨场弥补。** 上月 \(\Pi=-50\)。本月**另一场** \(S=100\) → 池子进 20。平台签 Claim cover 得 20，\(\Pi\) 仍为 \(-50\)，`cover_paid` \(=20\)，未补 \(=30\)。后面还有盈余可以继续补到未补为 0。

## 11. `/lp` 领取顺序

1. **Draw H**（有抽取时，这是亏损入账）
2. **Premium**
3. **Surplus**（情形 A，按排名）
4. **Fund cover**（把 \(S_C\) 打入协议池，谁都可以点，随时可点）
5. **Unlock** 未用 \(D\)（或作废路径）
6. **Claim cover**（平台签名；未补 \((-\Pi)^+-\texttt{cover\_paid}>0\)）

有 \(H\) 不要跳过 Draw，否则 \(\Pi\) 记不上这笔亏损。
